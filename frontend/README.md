# 🚖 Uber Clone (MERN Stack)

A full-stack Uber Clone built using the MERN Stack. This project replicates the core user authentication flow of Uber with separate modules for Users and Captains (Drivers). The frontend is developed using React, Vite, Tailwind CSS, and React Router, while the backend (coming next) will handle authentication, ride booking, maps, payments, and real-time communication.

